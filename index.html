Chưa Mở Tài Liệu PDF

Giao diện chỉnh sửa phong cách Microsoft Word.
Nhấn phím tắt Ctrl + O hoặc vào menu Tệp để mở tài liệu.

1. Chọn file PDF

Hoặc kéo thả file PDF vào khung bên phải. Chuyển đổi ngay trên máy bạn, file không bị gửi đi đâu.

2. Tùy chọn giữ định dạng

Mặc định bật cả hai kiểu bảng là cách giữ bố cục sát bản gốc nhất. Nếu bản Word bị vỡ bố cục, thử tắt "bảng không viền".

Nâng cao: nguồn bộ chuyển đổi

Bộ chuyển đổi (~55 MB) tải một lần từ mạng rồi được trình duyệt lưu lại. Muốn dùng offline, đặt bộ này trên máy chủ nội bộ rồi nhập địa chỉ vào đây.

3. Chuyển đổi

DANH SÁCH FILE PDF → WORD
Chưa chọn file nào. Kéo thả PDF vào đây hoặc bấm "Chọn file PDF".

2. Tùy chọn giữ định dạng

Bảng có đường viền được dựng thành ô Excel (kể cả ô gộp), giữ font, đậm/nghiêng, màu chữ, màu nền, căn lề, độ rộng cột và chiều cao dòng. Chữ ngoài bảng được đặt theo vị trí. Bảng không viền thường vẫn thành các cột thẳng hàng, bật dò bảng nếu muốn có đường kẻ.

3. Tùy chọn

Tích chọn các bước bạn muốn xử lý trên file (chạy liên hoàn 1 lần ra file hoàn chỉnh):

Với "theo khoảng trang", mỗi mục cách nhau dấu phẩy sẽ ra một file riêng. Với "trích", các trang gom chung một file.

📐 KÍCH THƯỚC LỀ mm

Trang lẻ (1, 3, 5...): lề trái là gáy sách; Trang chẵn (2, 4, 6...): lề phải là gáy sách.

👁️ MÔ PHỎNG LỀ TRỰC QUAN Xem trước khổ A4
Tỉ lệ co: 100%

Nên đặt 5-10 mm nếu bản scan có viền đen, bóng đổ hoặc dấu bấm ghim ở mép. Trang bị bỏ được liệt kê ngay dưới tên file, hãy xem lại kết quả trước khi dùng.

Ba mức đầu giữ nguyên chữ và bố cục, chỉ nén lại các ảnh nhúng trong PDF (hiệu quả nhất với PDF scan hoặc nhiều ảnh). Mức "Tối đa" biến cả trang thành ảnh JPEG, nhỏ nhất nhưng không còn chọn/tìm chữ được; có thể OCR lại sau. Nếu không giảm được dung lượng, tool giữ nguyên file gốc.

Thứ tự trang theo thứ tự danh sách bên phải (dùng nút ↑ ↓ để đổi). Tất cả ảnh gộp thành một file PDF.

Chữ nhận dạng được đặt vô hình đè lên ảnh scan, nên bạn tìm kiếm, chọn và copy chữ được. Sau khi OCR, dùng file kết quả ở các tab PDF → Word / Excel / So sánh. Lần đầu cần tải dữ liệu nhận dạng (khoảng 15 MB), sau đó được lưu lại trong trình duyệt.

Cần biết mật khẩu mở file. Tool không bẻ khóa mật khẩu.

Nâng cao: nguồn bộ xử lý

Chức năng mật khẩu dùng chung bộ PyMuPDF với tab PDF → Word (~55 MB, tải một lần).

Ô trống sẽ bị xóa khỏi file. Các ô được điền sẵn từ file đầu tiên trong danh sách.

Ví dụ bỏ trang bìa: đặt "Bắt đầu đánh từ trang" = 2.

Định dạng: Tiêu đề | số trang. Thêm dấu - đầu dòng để làm mục con (-- cho cấp 3).
